# Mildred Birthday Website

## Run locally
If you already started a local server, open:
- Landing: `http://localhost:3000/birthday/landing.html`
- Login: `http://localhost:3000/birthday/login.html`
- Birthday animation: `http://localhost:3000/birthday/index.html`

## What it includes
- Landing page → Login page → Birthday animation page
- Sweet birthday wishes text
- Animated countdown (days/hours/minutes/seconds)
- Confetti-like sparkle burst (canvas)
- Ambient floating particles
- Stars animation on the login page

## Notes
- Birthday date is interpreted from the login input.
- Default fallback is **7/08** if you open `index.html` directly.
